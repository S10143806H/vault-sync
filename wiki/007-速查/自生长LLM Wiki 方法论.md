# 自生长本地 AI 知识库

> 一句话：把「原始资料」持续喂进本地文件夹，让 AI 定期**消化、沉淀、迭代**，知识库自己越长越值钱，最后能直接**产出成果**（文档 / PPT / 视频）。
> 这正是本 vault（`AI赋能`）采用的 **[[karpathy]] LLM-Wiki 模式**：人选源与提问，LLM 写页、维护交叉引用、记流水账。

---

## 一、核心思想

传统笔记的痛点是**只进不出**——收藏了大量资料却从不复盘，信息越堆越乱。
自生长知识库把「收集 → 整理 → 复盘 → 输出」做成一条**由 AI 驱动的自动闭环**：

- **人**负责：选源（喂料）、提问（触发）。
- **AI**负责：消化原始资料、抽取高价值内容、沉淀可复用模版、迭代更新、输出成果。

信息利用率随时间**复利增长**，故称「自生长」。

---

## 二、四层文件夹流水线

整套系统由 **4 个文件夹 + 3 个 AI 动作** 组成，形成一条可循环的流水线。

### 1️⃣ 原始资料 → /raw（人工投喂）
用来存放未经处理的原始资料
![[Pasted image 20260916110624.png|518]]

> 网页、论文、截图、视频、会议纪要等**不可变原始源**，原样丢进 **文件夹 A**。
> 对应本 vault 的 `raw/` 目录——**LLM 只读不改，单一事实来源**。

### 2️⃣ 高质量文件夹 → /wiki
所有生成和归类的页面都在这

![[Pasted image 20260916110647.png|521]]

> AI 定期读取 A 的杂乱原料，**抽要点、去噪、结构化**，整合成人能读、能检索的高价值笔记，存入 **文件夹 B**。
> 对应本 vault 的 `wiki/` 概念页 / 实体页 / 综述。

### 3️⃣ 高质量文件夹 B —「AI 沉淀」→ 可复用模版库 C

![[Pasted image 20260916110703.png|532]]

> 从 B 的成熟笔记里**提炼可复用的结构与套路**（写作模版、分析框架、Prompt 模式），沉淀进 **模版库 C**，让下一次产出更快更稳。

### 4️⃣ 全流程闭环：A → B → C → D →「AI 自动迭代」

![[Pasted image 20260916110731.png]]

> 引入 **输出文件夹 D**（成品：文档 / PPT / 视频），并把产出反馈回 B，形成**自动迭代**的闭环：
>
> ```
> 原始文件夹A ──消化复盘──▶ 高质量文件夹B ──AI沉淀──▶ 可复用模版库C
>                              ▲                          │
>                              └──── 输出文件夹D ◀────────┘
>                                     （AI 自动迭代）
> ```

---

## 三、四个文件夹速查表

| 文件夹 | 角色 | 内容 | AI 动作 | 本 vault 对应 |
|---|---|---|---|---|
| **A 原始文件夹** | 进料口 | 网页 / 论文 / 截图 / 视频 / 会议纪要 | — （人工投喂） | `raw/` |
| **B 高质量文件夹** | 知识沉淀 | 去噪、结构化后的高价值笔记 | 定期消化复盘 | `wiki/` |
| **C 可复用模版库** | 方法沉淀 | 写作模版 / 分析框架 / Prompt 模式 | AI 沉淀 | schema · 模版 |
| **D 输出文件夹** | 出料口 | 文档 / PPT / 视频等成品 | 输出 + 自动迭代 | 成果导出 |

---

## 四、映射到本 vault（AI赋能）

本知识库即该模式的落地实现，三层结构一一对应：

| 视频概念 | 本 vault 结构 | 谁维护 |
|---|---|---|
| 原始文件夹 A | `raw/`（不可变源） | 人 |
| 高质量文件夹 B + 模版库 C | `wiki/`（LLM 维护） | LLM |
| 自动迭代规则 | `CLAUDE.md`（Schema） | 人 + LLM |
| 流水账 | [[log]]（只追加：ingest / query / lint） | LLM |
| 全站目录 | [[index]] | LLM |

工作流：**Ingest（摄入）→ Query（查询）→ Lint（体检）**，详见根目录 `CLAUDE.md`。

## 五、落地工具

- **[[Obsidian]]** — 本地 Markdown 知识库，`[[双链]]` 天然适配交叉引用。
