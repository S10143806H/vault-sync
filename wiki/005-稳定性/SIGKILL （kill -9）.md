Linux 用"信号"通知进程。对比两种"叫进程退出"：

┌─────────────┬─────────┬────────────────────────────────────────────────┐
│    信号     │  命令   │                      含义                      │
├─────────────┼─────────┼────────────────────────────────────────────────┤
│ SIGTERM(15) │ kill    │ "请善后后退出"——进程可捕获、优雅关闭           │
├─────────────┼─────────┼────────────────────────────────────────────────┤
│ SIGKILL(9)  │ kill -9 │ "立即处死"——进程无法捕获、来不及善后、当场毙命 │
└─────────────┴─────────┴────────────────────────────────────────────────┘

我们用 kill -9 就是故意模拟 [[SurfaceFlinger|SF]] 毫无预警地暴毙，测系统能不能自己把它拉起来。
- 关键：SIGKILL 本身通常不产生 [[tombstone（墓碑 验尸报告）|tombstone]]（是"处决"不是"崩溃"）；但被杀进程连累的其他进程可能崩 → 所以那 4 个墓碑要看一眼是不是噪声。
