## 推荐工具：xg（ws）

> 开发推荐使用方式，比手工 repo init 更简洁。

```bash
# 1. 克隆 ws 工具
git clone ssh://gerrit.guasemi.com:29418/xg/ws
cd ws

# 2. 查看所有可下载组件
./xg list

# 3. 下载组件代码（默认 gua-master 分支）
./xg sync all-dev

# 4. 查看可用编译配置
./xg build --list

# 5. 选配置编译
./xg build -c build/config/guav100/guav100.json
```

参考文档：`http://gerrit.guasemi.com/plugins/gitiles/xg/ws`

## 手工 repo 下载（组件级）

> 以下为各组件的原始 repo init 命令，推荐先用 xg 工具替代。

### 整版本

```bash
# gua 全源码（全员可用）
repo init \
  -u ssh://gerrit.guasemi.com:29418/psw/manifest \  # manifest 仓库地址（定义要下载哪些仓库及版本）
  --repo-url http://gerrit.guasemi.com/git-repo \   # repo 工具本身的内网下载源
  --git-lfs \                                        # 启用 LFS，下载大文件（驱动、二进制等）
  -g all,-libs,\                                     # 下载 all group，排除 -libs（用预编译包替代）
     -j6-keys,-nlp-asr-keys,-security-keys,-vlm-keys,\ # 排除各类 key 仓（权限管控，普通研发无权限）
     -pie,-hypervisor,-security,-mali-valhall,-gpu-mali,\ # 排除虚拟化和安全组件（权限管控）
     security-libs,pie-libs,valhall-libs,security-keys-libs,\ # 包含对应预编译库（替代源码）
     boot,ppl,-aaos-app \                            # 包含 boot；排除 aaos-app（单独拉）
  --depth=1                                          # 浅克隆（只取最新一个 commit，大幅减少下载量）
repo sync -j8 --no-tags   # -j8：8 线程并发（勿超过 8）；--no-tags：不下载 tag，加速同步
# 编译
./build.py -c build/config/guav100/guav100.json
```

```bash
# cherry 二进制版本
repo init \
  --git-lfs \                                        # 启用 LFS
  -u ssh://gerrit.guasemi.com:29418/psw/manifest \  # manifest 仓库
  -b gua-master \                                    # 指定分支（主线）
  -m default.xml \                                   # 指定 manifest 文件（默认清单）
  -g default,-commercial,chery \                   # default group + cherry 专属仓；排除商业授权仓
  --repo-url ssh://gerrit.guasemi.com:29418/git-repo \ # repo 工具下载源
  --depth=1                                          # 浅克隆
repo sync -q -j8   # -q：静默输出；-j8：8 线程
```

### AAOS

```bash
repo init \
  -u ssh://gerrit.guasemi.com:29418/psw/manifest \  # manifest 仓库地址
  --repo-url http://gerrit.guasemi.com/git-repo \   # repo 工具内网源
  --git-lfs \                                        # 启用 LFS（AAOS 有大量二进制资源）
  -g aaos,\                                          # aaos：AAOS 核心仓库（framework、vendor 等）
     build,\                                         # build：编译工具链和脚本
     aaos-private,\                                  # aaos-private：厂商定制私有仓库
     -aaos-libs,\                     # -aaos-libs：排除 AAOS 预编译库（用二进制包替代，减少下载量）
     bpu,\                                           # bpu：BPU 神经网络处理器驱动和固件
     -bpu-libs                                       # -bpu-libs：排除 BPU 预编译库
repo sync \
  -c \          # 只同步 manifest 指定的当前分支（跳过其他分支历史，加速）
  -d \          # detach HEAD 到 manifest 精确 commit（确保多人版本一致）
  -j 8 \        # 8 线程并发（勿超过 8，否则 gerrit 卡顿）
  --no-tags     # 不下载 tag（减少网络传输）

# 编译（Android 标准方式）
source build/envsetup.sh   # 加载 Android 编译环境变量
lunch <产品>-user           # 选择产品配置（如 goldencar-user）
make -j32                  # 多核并行编译
# 或用封装脚本
./build.py aaos
```

### Cluster（仪表）

```bash
repo init \
  -u ssh://gerrit.guasemi.com:29418/psw/manifest \  # manifest 仓库
  --repo-url http://gerrit.guasemi.com/git-repo \   # repo 工具源
  --git-lfs \                                        # 启用 LFS
  -g linux,\                                         # linux：Linux kernel 仓库
     build,\                                         # build：编译工具
     cluster,\                                       # cluster：仪表主代码（Yocto 层）
     cluster-priv,\                                  # cluster-priv：仪表私有仓库
     -cluster-priv-libs                              # -cluster-priv-libs：排除预编译库
repo sync -j8 --no-tags

# 编译（Yocto）
cd linux/yocto
./build.sh <产品配置>   # Yocto bitbake 封装脚本，指定 MACHINE/DISTRO
# 或用顶层封装
./build.py -c build/config/guav100/guav100.json cluster
```

## 注意事项

- `repo sync -j` 线程数**不要超过 8**，否则会造成 gerrit 卡顿
- `pie`、部分 `key` 仓有权限管控，无权限用 QB 编译或联系 owner
- `bl32` 暂无独立编译命令，归属 security group
- ADAS (`adas`) group 需确认 `groupx`，联系 owner 确认权限
