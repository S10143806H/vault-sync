# 01 - 一帧画面是怎么上屏的（大图景）

> 目标：建立整条**图形管线（graphics pipeline）**的直觉。
> 上级：[[000-GFWK图形框架总览]]

## ① 为什么需要这套东西

屏幕上任何一帧，都是**多个来源**拼出来的：导航地图 + 状态栏 + 弹窗 + 视频……每个来源是一个 App（[[生产者]]）。如果每个 App 都直接往屏幕硬件写像素，会**互相踩踏、撕裂、抢内存**。所以需要一个"班长"来统一收集、统一拼版、统一贴上黑板——这就是图形框架存在的理由。

## ② 一帧的旅程（The Pixel's Journey）

```
同学画稿 → 领白纸 → 放提交槽 → 班长拼版 → 挂墙工/美术委员合成 → 换纸铃踩点 → 贴上黑板
(App)    (Gralloc) (BufferQueue) (SF)        (HWC / GPU)            (VSync)       (DPU)
```

逐环拆解：

1. **领白纸**：App 向 [[Gralloc]]（发纸员）申请一块 buffer（白纸）。Gralloc 从 [[dma-buf heap]]（纸库房）取真实内存，按 App 要的**格式**（RGBA_8888/NV12…）和**用途 usage**（GPU 渲染？视频解码？）裁好纸。
2. **画稿**：App 把像素画进白纸（CPU 写 / GPU 渲染）。
3. **放提交槽**：画完，App 把纸 `queueBuffer` 丢进 [[Buffer Queue]]（提交槽）。这是**生产者-消费者模型**的核心。BufferQueue 管理槽位状态机：`FREE → DEQUEUED → QUEUED → ACQUIRED`，同一槽位不会被两个同学同时领走。
4. **班长取纸 + 拼版**：[[SurfaceFlinger]]（班长，消费者）从每个提交槽 `acquireBuffer` 取纸，把 N 个 App 的稿子按 **z-order**（谁压谁）拼成完整一版 = **合成 composition**。
5. **谁来贴**：能用硬件就用 [[HWC]]（挂墙工，磁铁 overlay 直接贴）；HWC 层数/格式不支持时**回退 GPU**（美术委员手工画）。省电是 HWC 的价值，两者结果必须完全一致，否则切换瞬间颜色/透明度跳变。
6. **踩换纸铃贴上黑板**：一切等 [[VSync]]（换纸铃，60fps = 每 16.6ms 一响）。踩点提交给 DPU 扫描输出，不踩点就**撕裂 tearing**（黑板上下两半是不同帧）。
7. **举牌同步**：环节之间不是"画完立刻能取"，靠 [[Fence]]（"画完了"举牌）通知"这张纸好了"。GPU 还没渲完，fence 未 signal，班长不能取——**否则拿到半成品贴上黑板 = 花屏 / kernel panic（UAF）**。

## ③ 一句话记住每个角色

| 教室角色 | 技术名 | 职责 |
|---|---|---|
| 纸库房 | [[dma-buf heap]] | 真实内存池（内核） |
| 发纸员 | [[Gralloc]] | 按格式分配 buffer |
| 提交槽 | [[Buffer Queue]] | 生产者/消费者交接，槽位状态机 |
| 班长 | [[SurfaceFlinger]] | 收纸、拼版、统一上屏 |
| 挂墙工 | [[HWC]] | 硬件合成（省 GPU） |
| 美术委员 | GPU | 软件合成（HWC 回退） |
| "画完了"举牌 | [[Fence]] | 生产者→消费者完成同步 |
| 换纸铃 | [[VSync]] | 防撕裂，固定 60Hz 节拍 |
| 隔壁班黑板 | [[composer_stub]] | 跨 SoC 送到仪表屏 |

## ④ 常见误区

- ❌ "App 直接画到黑板上" — 不，App 只画到自己的白纸，**班长统一拼版后才贴上黑板**。
- ❌ "合成一定用 GPU" — 优先 [[HWC]] 硬件合成，GPU 是回退，用 GPU 反而费电/发热。
- ❌ "Gralloc 挂了 = 黑屏" — 不，已在槽里的纸还在，画面**冻在最后一帧**；只是新帧无法分配，不会立刻全黑。
- ❌ "Fence 防槽位冲突" — Fence 防的是**消费者提前取半成品**；槽位冲突由 **BufferQueue 状态机**负责。
- ❌ "buffer 画完就能用" — 必须等 [[Fence]] signal，否则读到半成品 = 花屏/UAF。

## ⑤ 这条管线 = 稳定性 bug 的高发地图

| 环节出问题 | 现象 | 对应测试维度 |
|---|---|---|
| 提交槽反压失效 | buffer 溢出/卡死 | BOUND（边界）→ [[TC_SF_BOUND_002]] |
| 班长崩溃 | 黑屏、ANR | FAULT（故障注入）→ [[TC_SF_FAULT_001]] |
| 白纸分配泄漏 | fd/内存只增不减 | LEAK（泄漏） |
| 举牌用错 | 花屏/kernel panic | 跨SoC fence UAF → [[05-Fence与跨SoC同步]] |
| 挂墙工坏参数 | 返回错误码，不崩 | FAULT → [[TC_HWC_FAULT_002]] |
