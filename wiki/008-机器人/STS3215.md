# STS3215 速查

## 规格

| 项 | 7.4V 版（C001，1:345） | 12V 版 |
|---|---|---|
| 堵转扭矩 | 约 19.5 kg·cm（测试电压各家说法不一，6V 或 7.4V） | 约 30 kg·cm @12V |
| 堵转电流 | 约 2.5 A @7.4V | 约 2.7 A |
| 速度 | 0.192 s/60° @7.4V | 0.222 s/60° |
| 分辨率 | 4096 步/圈（2048 = 中位 = 0 rad） | 同 |
| 通信 | 半双工 TTL 单总线，出厂 **1 Mbps、ID 1** | 同 |
| 价格 | 约 ¥98（淘宝） | — |

**实测数据（社区）：** 回差 0.87°；连续摆动可到 71 ℃，没有过热保护；实际堵转约 1.86 N·m，比仿真设定的 3.23 N·m 小。

## 协议（与 Dynamixel 1.0 同构）

- **指令包**：`FF FF ID LEN INSTR P... CHK`，其中 `LEN = 参数数 + 2`，`CHK = ~(ID+LEN+INSTR+ΣP) & 0xFF`
- **应答包**：`FF FF ID LEN ERR P... CHK`
- **指令**：PING 0x01、READ 0x02、WRITE 0x03、SYNC_READ 0x82、SYNC_WRITE 0x83；广播 ID 为 0xFE
- **测试向量**（rustypot）：
  - sync_read(ids=[11,12], addr=30, len=2) = `FF FF FE 06 82 1E 02 0B 0C 42`
  - sync_write(ids=[11,12], addr=30, [00 00],[0A 14]) = `FF FF FE 0A 83 1E 02 0B 00 00 0C 0A 14 1F`

## 常用寄存器（十进制地址）

| 地址 | 名称 | 说明 |
|---|---|---|
| 5 | ID | EEPROM |
| 6 | 波特率 | 0 = 1M，1 = 500k |
| 7 | 应答延时 | 单位 2 µs，默认 0 |
| 21 / 22 / 23 | P / D / I | Open Duck：P = 32（运行时腿 30、头 8），I = D = 0 |
| 33 | 模式 | 0 = 位置模式 |
| 40 | 扭矩开关 | |
| 41 | 加速度 | Open Duck 设 0 |
| 42 | 目标位置 | u16 |
| 55 | Lock | 0 = 写 EEPROM 区会掉电保存；1 = 只改 RAM（上电默认 1） |
| 56 | 当前位置 | u16。和 58 连续，可以一次读 4 字节 |
| 58 | 当前速度 | bit15 为符号位，单位 step/s；rad/s = 2π·v/4095 |
| 62 / 63 | 电压 / 温度 | 电压单位 0.1V，温度单位 ℃ |
| 85 | 最大加速度 | ⚠ 出厂常为 50，**必须改成 0**，否则比仿真慢约 3 倍 |

**换算（rustypot）：** `rad = 2π·raw/4096 − π`；`raw = 4096·(π+rad)/(2π)`

## MCU 接口

- **为什么不能直接接**：MCU 的 UART 是 TX/RX 分开的两根线，总线只有一根 DATA 线，中间要加半双工转换。
- **推荐电路**：74LVC1G126 + 74LVC1G125 + MMBT3906 自动换向（Feetech / Waveshare 参考电路），全 3.3V，**不需要方向脚**。详见 [[Ameba鸭子-可行性调研与详细设计#4.2.2 第二阶段：自制 Ameba Duck Carrier 载板（详设）]]。
- **成品模块**：Waveshare Bus Servo Adapter (A)（约 ¥27）、Feetech FE-URT-1。
- **1 Mbps 时间账**：14 路 sync_write 位置约 0.5 ms；sync_read 位置+速度约 1.6 ms，另加应答延时。
