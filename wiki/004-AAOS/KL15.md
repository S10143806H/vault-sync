# KL15

汽车电气标准中的**点火电源信号**（来自德标 DIN 72552）。KL15 高 = 钥匙拨到 ACC/ON 位，车机上电；KL15 低 = 钥匙拔出/锁车，车机准备下电。

- 控制： `vehicle_power_context.set_vehicle_awake(True/False)`
    - `True` → KL15 拉高（唤醒）
    - `False` → KL15 拉低（进休眠流程）
- 读状态： `power = vehicle_power_context.power("kl15")` → `power.read_power_status()`
- 相关配合： `start_soc_periodic(80)` / `stop_all_can_signals()`（拉低前发 SOC、停 CAN）

## 在 AAOS 中的作用

| KL15 状态 | 车机行为 |
|---|---|
| 高（上电） | 系统启动 / 从 [[STR]] 唤醒 |
| 低（下电） | 进入 [[STR]] 挂起 / 关机流程 |

## 稳定性测试关联

`test_006_kl15_str`：模拟锁车（KL15 拉低）→ 车机进 [[STR]] → 解锁（KL15 拉高）→ 秒醒，验证唤醒后显示正常。

测试中通过 `set_vehicle_awake(True/False)` 控制 KL15 高低。
