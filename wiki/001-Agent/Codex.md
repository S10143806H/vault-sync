**Codex 分叉是什么**
Codex 分叉通常指从当前线程或任务上下文复制出一个新线程/新工作区分支，让另一个方向继续推进。
作用：
1. 保留当前上下文，不破坏主线。
2. 并行尝试不同方案。
3. 把风险较高的实验隔离出去。
4. 让一个问题拆成多个独立任务，比如：
    - 主线程继续分析算法。
    - 分叉线程专门跑 GTMP。
    - 另一个分叉线程专门写文档或脚本。


**Codex 钩子是什么**
钩子一般是指在某个事件发生时自动执行的动作。例如：
- 任务开始前检查环境。
- 每次运行命令前加载变量。
- 提交代码前跑 lint/test。
- 任务完成后归档、通知、生成报告。
- 监听某类事件后触发自动化。

钩子的核心作用是“把重复流程自动化”，减少人工记忆步骤。
如果没有钩子，很多事情要靠人或 agent 每次记得做；有钩子后，可以变成固定流程。
