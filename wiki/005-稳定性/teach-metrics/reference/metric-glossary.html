指标术语表

全课统一用词。新课出现的术语先在此登记。

术语定义在 autocase 里的例子
指标 metric数据源+度量+阈值判定 组成的一条判定链screen_not_black
数据源 source原始数据来自哪里,决定实时性/可靠性截图 / dumpsys / Prometheus
度量 measure把原始数据降维成一个可比标量image_bright_ratio → 2.2%
阈值 threshold判定用的界线;没有它只是日志min_bright_ratio=0.0005
判据指标 assertiongate 用例 通过/失败 的指标判屏黑 → FAIL
监控指标 telemetry只记录看趋势,不 gate 结果FPS / GPU / 内存 snapshot
gauge可增可减的瞬时量sys_gpu_usage(45%)
counter只增不减的累计量崩溃次数 / tombstone 数
基线 baseline正常态的参考值,监控指标据此判"是否恢复"kill 前的 FPS
误判 false verdict阈值/度量选错导致的错误判定旧 mean<5 误判空调屏为黑
